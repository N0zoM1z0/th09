# Reconstruction source

This directory contains maintained reconstruction units admitted after bounded
target, ownership, interface, and candidate translation-unit review. Source
presence is not an exactness claim: `config/functions.csv` records the source
mapping and review state, while `config/matches.csv` contains only canonical
target-bound exact matches.

The repository does not yet claim whole-program product closure. Build and
compare individual configured units through `config/match-units.toml` and the
scripts documented in `docs/RE_WORKFLOW.md`.
